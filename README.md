# RC Receiver PCB for ESP32-WROOM

Bu repo, [RC-Receiver-ESP](https://github.com/failsmakes/RC-Receiver-ESP) projesinde kullanılan kod için hazırlanmış **ESP32-WROOM tabanlı RC alıcı devresinin PCB çizimini** içerir. Tasarım **KiCad** kullanılarak yapılmıştır.

## 📌 Proje Amacı
RC-Receiver-ESP yazılımını donanım üzerinde çalıştırmak için uygun bir PCB tasarımı sağlamak. Bu kart, ESP32-WROOM modülü ile RC sinyallerini alıp işleyebilecek şekilde düzenlenmiştir.

## 🛠️ Özellikler
- ESP32-WROOM modülü için uygun footprint  
- RC alıcı bağlantıları için pin header düzeni  
- Güç girişleri ve regülasyon devresi  
- Programlama ve debug için gerekli bağlantılar  
- Kompakt ve prototip dostu tasarım  

## 📂 Repo İçeriği
- `RC_Receiver_PCB_ESP32-WROOM.kicad_pcb` → PCB çizimi  
- `RC_Receiver_PCB_ESP32-WROOM.sch` → Şematik dosyası  
- `gerber/` → Üretim için gerekli Gerber dosyaları  
- `README.md` → Bu açıklama dosyası
